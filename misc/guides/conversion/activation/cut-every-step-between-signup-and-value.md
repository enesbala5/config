# Cut every step between signup and first value

**Feeds stage:** audit

Time-to-value is the primary onboarding target: remove steps rather than
explaining them. Test fewer required steps, optional instead of required fields,
skip options for non-critical steps, pre-filled templates, OAuth account
linking, and moving email verification to after onboarding.

Test an empty state against pre-populated example data, and test permission
timing — ask when the user first needs the capability, not at signup. Every
step that does not create value is a candidate for removal.
