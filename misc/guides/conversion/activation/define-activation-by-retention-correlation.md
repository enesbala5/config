# Define activation as the action that predicts retention

**Feeds stage:** audit

Find the aha moment empirically: compare retained users with churned ones and
pick the earliest action that correlates most strongly with future engagement.
Make it a concrete, observable event, not a vague feeling of value.

Examples by product type: project management — create first project and add a
team member; analytics — install tracking and see first report; design tool —
create first design and export/share; marketplace — complete first transaction.
Ask what retained users do that churned users do not, and whether cohort
analysis on the two groups exists.
