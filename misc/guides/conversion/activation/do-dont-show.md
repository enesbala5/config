# Make users do the thing, not read about it

**Feeds stage:** audit

Prefer interactive onboarding over tutorials: doing the thing beats learning
about the thing. Put the user into the real workflow and let value come from
completing it — a screen that explains a feature is a substitute, not a result.
When guidance is unavoidable, test interactive tours against video tutorials
and self-paced against guided flows, and keep the guidance at the point of
action.
