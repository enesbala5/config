# Match the onboarding path to the product type

**Feeds stage:** audit

Use the product's natural loop as the checklist skeleton:

- B2B SaaS — setup wizard → first value action → team invite → deeper setup.
- Marketplace — complete profile → browse → first transaction → repeat loop.
- Mobile app — permissions → quick win → push setup → habit loop.
- Content platform — follow/customise → consume → create → engage.

The activation event and step order should reflect that loop, not a generic
wizard.
