# Personalise onboarding by role, goal or experience

**Feeds stage:** audit

Segment the onboarding path on something the user told you or did: role, stated
goal, use-case answer, industry, or beginner-versus-expert experience. Then
make the defaults match — role-specific dashboard, relevant templates, industry
examples, dynamic recommendations and a personalised welcome.

Personalisation only helps when the default view is actually relevant to the
segment; a single generic path cannot be relevant to every goal.
