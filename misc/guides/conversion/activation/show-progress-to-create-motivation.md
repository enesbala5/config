# Show progress to create motivation

**Feeds stage:** audit

Make the path visible: show advancement, completion percentages and celebrate
completions. Test progress bars, "X% complete" messaging, celebration moments,
checklist length (3–5 versus 5–7 items) and milestone rewards; consider starting
the user at a non-zero point if earlier steps are already done.

Progress is a motivation mechanic, not decoration — a flow with no visible end
feels longer than one that shows what remains.
