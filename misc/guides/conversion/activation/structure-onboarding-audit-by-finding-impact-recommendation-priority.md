# Structure onboarding findings as finding, impact, recommendation, priority

**Feeds stage:** audit

Report each onboarding issue in four parts: Finding (what is happening), Impact
(what it costs), Recommendation (what to change) and Priority (why it goes
first).

When designing the flow, deliver the activation goal, step-by-step flow,
checklist items, empty-state copy, email trigger list and a metrics plan — the
triggers and measurement belong in the design, not as an afterthought.
