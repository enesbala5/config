# Organize experiments by page type and dimension

**Feeds stage:** verify

Group experiment ideas first by page, then by the dimension being changed:
homepage (hero, trust/social proof, features/content, navigation/UX), pricing
(price presentation, pricing UX, objections, trust), demo request (form, page
content, CTA/routing), resource/blog (content CTAs, resource section), landing
page (message match, conversion focus, length), feature page (presentation,
conversion path) and cross-page/sitewide tests. The grouping exposes which part
of the funnel a test actually affects.

For onboarding there is no single page to group by, so group by dimension
instead: flow simplification (step count, ordering, progress), guided experience
(tours, CTA, UI guidance), personalisation (role/goal segmentation, dynamic
content), quick wins and engagement, email and multi-channel, re-engagement, and
technical/UX (performance, mobile, accessibility).

Paywalls are another in-app surface with no single page: group them by dimension
— trigger and timing, design/layout and value presentation, pricing presentation,
copy (headlines, CTAs, objection handling), trial structure and expiration,
personalisation, and frequency/dismiss behaviour. The grouping shows which part
of the upgrade funnel a test actually affects.
