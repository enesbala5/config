# Test paywall personalisation by usage and segment

**Feeds stage:** verify

Adapt the paywall to the user instead of showing everyone the same screen: write copy from the features they have used, highlight their most-used premium features, show their own usage stats ("you've created 50 projects") and recommend a plan from their behaviour.

Test segment-level variation too — different screens for power versus casual users, B2B versus B2C messaging, industry-specific value propositions, role-based feature highlighting and messaging matched to traffic source. Personalisation is a hypothesis to test, not an assumption that more detail converts.
