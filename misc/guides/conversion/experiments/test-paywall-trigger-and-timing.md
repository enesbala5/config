# Test paywall trigger timing and gate type

**Feeds stage:** verify

Treat the trigger as a testable lever: after the aha moment versus at the moment of feature attempt; an early trial reminder (7 days) versus a late one (1 day before expiry); a set number of actions completed versus days elapsed; usage-pattern triggers versus time-based ones. Also test hard gate versus soft gate (preview plus prompt), feature lock versus usage limit as the primary trigger, in-context modal versus dedicated upgrade page, and banner reminder versus modal prompt.

Change one dimension at a time so the result says which timing or gate type moved conversion.
