# Test how the paywall presents value

**Feeds stage:** verify

Testable ways to frame the paid value: a feature list versus benefit statements; what the user will lose (loss aversion) versus what they will gain; a personalised value summary based on actual usage; a before/after demonstration; and an ROI or value-quantification calculator.

Visual treatment is a separate axis: product screenshots or previews, a short demo video or GIF, illustration versus product imagery, animated versus static, and a progress visual of what the user has accomplished. Vary one axis per test so the result is attributable.
