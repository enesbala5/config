# Track the form funnel by field

**Feeds stage:** verify

Measure form start rate (views to started form), completion rate (started to
submitted), field drop-off, error rate by field, time to complete overall and by
field, and the mobile-versus-desktop split. Track views, first field focus, each
field completion, errors, submit attempts and successful submissions so you can
see which field loses people instead of only seeing the final submission count.
