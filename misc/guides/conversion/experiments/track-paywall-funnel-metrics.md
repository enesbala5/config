# Track the paywall funnel from impression to revenue and churn

**Feeds stage:** verify

Measure the whole path, not just clicks: paywall impression rate, click-through to upgrade, upgrade completion rate, revenue per user and churn rate after upgrade. A change that raises click-through but lowers completion or raises post-upgrade churn is a loss, not a win.

Segment these metrics by trigger type and timing so the data says which moment and which prompt actually produced the revenue.
