# Archived sources

Verbatim copies of the four selected conversion skills. Each skill archive
includes its SKILL.md body (with SKILL.md's YAML frontmatter omitted and
recorded in the archive frontmatter) plus every prose file in that skill's
`references/` directory. Frontmatter records provenance only. `evals/`
directories are test fixtures, not source prose, and are deliberately skipped.
Lessons are intentionally orphaned and never link back here.

The selection and its scope are recorded in the [guide README](../../README.md).
