# Ask for the upgrade after the aha moment

**Feeds stage:** audit

Show the paywall only after the user has experienced real value — after the aha moment, not before it. Time the ask to the activation event the product has identified, and let the upgrade read as the natural next step rather than an interruption.

Counterexample: prompting during onboarding, or before any value is delivered, asks for a commitment on trust the product has not earned; it is listed as a conversion killer. A prompt after value but before frustration converts from a position of demonstrated worth.
