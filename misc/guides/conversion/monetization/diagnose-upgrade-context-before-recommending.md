# Establish upgrade context before recommending

**Feeds stage:** audit

Before advising on a paywall, pin down three things: the upgrade context (freemium to paid, trial to paid, tier upgrade, feature upsell or usage limit), the product model (what is free, what is gated, what triggers prompts, current conversion rate) and the user journey (when the prompt appears, what the user has already experienced, what they are trying to do). Ask for the current free-to-paid conversion rate and the product's aha moment as well.

Recommendations without this context cannot say which moment is worth prompting at, or what "after value" means for this product.
