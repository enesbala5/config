# Diagnose the page before recommending

**Feeds stage:** audit

Before suggesting changes, identify the page type (homepage, landing, pricing,
feature, blog, other), the primary conversion goal (sign up, demo, purchase,
subscribe, download, contact sales) and where traffic comes from (organic,
paid, email, social). Also ask for the current conversion rate and target, the
signup/purchase flow after this page, any user research, heatmaps or session
recordings, and what has already been tried. Recommendations without this
context optimise for the wrong action.
