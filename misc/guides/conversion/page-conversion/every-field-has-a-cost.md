# Every form field has a cost

**Feeds stage:** audit

Each additional field reduces completion: roughly 3 fields is baseline, 4-6
fields cut completion by 10-25%, and 7+ fields by 25-50% or more. For every
field ask: is it absolutely necessary before we can help them? Can we get it
another way? Can we ask it later? Remove or defer any field that fails those
questions.
