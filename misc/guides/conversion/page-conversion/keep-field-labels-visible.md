# Keep field labels visible; placeholders are examples

**Feeds stage:** audit

Labels must remain visible while typing; a placeholder is an example, not a
label. Good: a visible "Email" label with `name@company.com` as the placeholder.
Bad: a field showing only `Enter your email address`, which disappears on focus
and leaves the user unsure what they are filling in. Add help text only when it
is genuinely helpful.
