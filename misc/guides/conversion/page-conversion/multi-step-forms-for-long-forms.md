# Use multi-step forms for longer forms

**Feeds stage:** audit

Split a form when it has more than 5-6 fields, logically distinct sections,
conditional paths, or complex data (applications, quotes). Use a "step X of Y"
progress indicator, one topic per step, easy questions first and sensitive ones
last, allow back navigation, save progress so a refresh does not lose data, and
mark required versus optional fields clearly.
