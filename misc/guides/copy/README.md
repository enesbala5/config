# Copy guide

Evidence for the global `copy` module. Sources are verbatim archives of the five
global skills the module supersedes; lessons are standalone ideas extracted from
them. The module holds rules derived from these lessons, never copies of them.

## Lesson conventions

- One idea per file, in one of the canonical buckets below.
- A lesson has a title, a `**Feeds stage:** <bucket>` line, and a short, concrete,
  actionable body with an example or counterexample when the source gives one.
- No `Source:` line and no link back to the archive: lessons are orphaned by design
  so they can be read without the article.
- Enrich an existing lesson rather than duplicating it; update the bucket README
  in the same pass as any write.

## Buckets

- `page-copy/` — web and marketing page copy, awareness inputs, structure, CTA.
- `editing/` — focused editing sweeps, quick passes, content refresh.
- `social/` — X batches and comment replies, voice registers, format bans.
- `longform/` — technical how-to posts, receipts, structure, frontmatter.
- `cross-cutting/` — no-fabrication, voice sourcing, ownership, deletion safety.

**Feeds stage** lines name the consuming intent (`write`, `revise`, `social`,
`longform`, `verify`) because the consuming module ships no pipeline layer.

## Consumers

The global `copy` module derives its rules from these lessons: workspace
`misc/modules/copy/`, router `misc/skills/copy/SKILL.md`. Rules point here by
bucket path; this guide never reads the module.
