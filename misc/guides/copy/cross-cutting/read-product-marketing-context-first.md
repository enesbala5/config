# Read product-marketing context before editing

**Feeds stage:** verify

Before editing, look for the project's product-marketing context
(`.agents/product-marketing.md`, `.claude/product-marketing.md`, or the legacy
`product-marketing-context.md`) and read it if present. Use its brand voice and
customer language to guide your edits so they match how the brand and its
customers actually speak.

Counterexample: a technical how-to post is not this register. Source its voice
from the author's own published posts instead — the product-marketing file is
the wrong voice document for that format.
