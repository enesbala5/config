# Run seven focused sweeps, looping back after each

**Feeds stage:** revise

Edit through seven sequential passes, each on one dimension, rather than one
unfocused review: Clarity, Voice and Tone, So What (benefit), Prove It
(evidence), Specificity, Heightened Emotion, Zero Risk (barriers near the CTA).

In a pass, mark problems without fixing them yet, then recommend specific edits
and verify they keep the original intent. After each sweep, loop back through
the earlier ones — a later edit can break an earlier fix. Multiple focused
passes catch issues a single everything-at-once review misses.
