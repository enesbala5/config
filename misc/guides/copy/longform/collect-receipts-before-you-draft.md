# Collect receipts before you draft

**Feeds stage:** longform

Do not invent a walkthrough. This author writes from a setup that already works,
so gather the real inputs first: the stack the reader already has, the painful
part, the end state in one sentence, real files/commands/paths/versions/distro,
what was deliberately skipped, and credits for anything adapted.

If a repo or file path is in play, mine its history before outlining. If
receipts are still missing after that, write the skeleton and wait — do not
fabricate configs, keybinds, or "typical" defaults to fill the gaps.
