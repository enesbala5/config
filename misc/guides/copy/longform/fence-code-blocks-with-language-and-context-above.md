# Fence code blocks with language and context above

**Feeds stage:** longform

Every code block is fenced with a language tag and has its goal or one-line
context *above* it. Show the file as the author keeps it, then say what the
reader must change (`remember to update [YOUR DOMAIN]`); after a rebuild or
switch step, show the path or command the reader should now have.

Stay on the portfolio highlighter languages (`javascript`, `typescript`, `bash`,
`json`, `svelte`, `ini`, `properties`, `ssh-config`, `nix`) unless the user asks
to add one.
