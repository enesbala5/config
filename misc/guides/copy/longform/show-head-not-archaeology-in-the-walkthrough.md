# Show HEAD, not archaeology, in the walkthrough

**Feeds stage:** longform

The walkthrough quotes the current HEAD files — the setup that works now — with
obvious placeholders for reader-specific values. Git history explains *why* a
flag exists and which pieces were polish; it never becomes the article's plot.

Do not paste hashes, `git log` output, or a changelog, and do not narrate the
search ("in commit abc…", "that's when it clicked"). A later commit that exists
because the first approach was insufficient is evidence for the Main Challenge
and a callout, not a section of its own.
