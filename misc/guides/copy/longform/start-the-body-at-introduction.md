# Start the body at Introduction

**Feeds stage:** longform

The page title comes from frontmatter; body headings start at `# Introduction`.
Do not repeat the title as an H1.

Use the fixed skeleton: `# Introduction` (situation, painful part, scope,
end-state promise), `# The Main Challenge` (why the obvious approach fails,
numbered needs), `## The Solution` (one tight need → mechanism map, then stop),
`# Process Walkthrough` with `## Key Requirements` and numbered steps,
`# Putting It Together` (verification checklist), `# Conclusion`. Prefer
"Putting It Together" over the older "Verify the Connection" heading.
