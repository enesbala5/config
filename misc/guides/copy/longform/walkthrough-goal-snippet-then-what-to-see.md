# Walkthrough step: goal, snippet, then what to see

**Feeds stage:** longform

Each numbered step has the same shape: goal in a sentence or a `Goal:` callout,
then the command or config, then what the reader should see or why a flag
exists. Keep placeholders obvious (`[YOUR DOMAIN]`, `${data.username}`); use
the author's real paths when the post is "how I did it".

Nest 1.1 / 1.2 only when a step is genuinely long. Name the messy reality —
what does not reload instantly, what does not survive reboot — rather than
implying a clean setup.
