# Write as a competent peer

**Feeds stage:** longform

Register: first-person technical how-to — a competent peer, not a teacher and
not a brand. Use `you` for steps and `I` for choices, failures and paths; name
the distro and tools actually used. Backtick tools, flags, paths, options and UI
labels (`stylix.polarity`, `host.docker.internal`); keep conventional
capitalization and use parentheticals to narrow a claim, not for jokes.

Ask almost no questions and never open with one. Let headings do the
transitioning, then `Now that we have X…` or `After a rebuild you should have:`.
