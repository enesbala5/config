# Translate features into customer benefits

**Feeds stage:** write

State what the product does as a feature, then state what that means for the
customer as the benefit — and lead with the benefit.

- Feature: what it does.
- Benefit: what the reader gains from it.

For every claim, literally ask "so what?" If the copy doesn't answer with a
deeper benefit tied to a real reader desire, add a "which means..." bridge. A
wall of features with no benefit connection is a list, not an argument.
