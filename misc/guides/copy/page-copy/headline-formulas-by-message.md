# Match the headline formula to the message

**Feeds stage:** write

Pick a headline formula that fits the one message the page must land, then fill
it with specifics. Families and examples:

- Outcome: "Turn your hard-earned sales into repeat customers"
- Problem: "Never miss a sales opportunity again"; "Stop chasing invoices.
  Start getting paid on time."
- Audience: "Advanced analytics for Shopify e-commerce"
- Differentiation: "The CRM that updates itself"
- Proof: "50,000 marketers use Drip to send better emails"

Keep the headline specific — a concrete formula beats a generic value
proposition.
