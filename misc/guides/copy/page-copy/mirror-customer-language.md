# Write in the customer's words, not the company's

**Feeds stage:** write

Use the words customers use to describe their problem; mirror voice-of-customer
from reviews, interviews and support tickets rather than internal terminology.
If a term would confuse an outsider, replace it with the plain word your reader
already uses. For corporate speak ("leverage synergies to optimize outcomes"),
ask "How would a human say this?" and use those words.
