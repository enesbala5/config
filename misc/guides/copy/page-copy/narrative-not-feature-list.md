# Build a persuasive narrative, not a feature list

**Feeds stage:** write

A run of features in a row is a list, not an argument.

- Weak: Hero → Feature 1 → Feature 2 → Feature 3 → Feature 4 → CTA.
- Strong: Hero with clear value prop → social proof bar → problem/pain → how it
  works → key benefits (2–3, not 10) → testimonial → use cases → comparison →
  case study → FAQ → final CTA with guarantee.

The strong version tells a story and answers objections; the weak one does
neither.
