# One idea per section, in logical order

**Feeds stage:** write

Each section should advance a single argument, and the sections should build a
logical flow down the page. If a section is trying to make two points, split it
before you write the copy. Alongside this "Rule of One", keep the "You Rule":
the copy speaks to the reader, not about the company. Re-check both after any
editing pass, since fixing one can disturb the other.
