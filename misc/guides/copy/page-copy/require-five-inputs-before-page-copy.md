# Require five inputs before writing landing or messaging copy

**Feeds stage:** write

Before drafting any brief, strategy or copy for a landing page, campaign page,
messaging or positioning, the human must explicitly supply all five: audience,
traffic source, stage of awareness, page format and the one primary action.
Research documents can inform your questions but never count as an answer.
Read page format off the project's canonical page-type-by-awareness ladder —
never choose it from preference, and never restate the ladder's mapping.

If any of the five is missing, ask once and then stop; do not infer, assume or
draft around the gap. Offer 2–3 concrete options drawn from the repo so a
one-line reply is enough (for example, audience: active repeat /
screening-frustrated / writing-anxious).
