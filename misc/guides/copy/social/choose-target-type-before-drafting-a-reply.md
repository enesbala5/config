# Choose the target type before drafting a reply

**Feeds stage:** social

A comment reply needs a target type. Infer it and state the pick in one line;
ask only when the goal is genuinely ambiguous. The target decides the shape, and
an excellent reply for one target is a failure for another.

What the target fixes:

- `promote-coverlttr` — product relevance inside a job-search conversation;
  mention it only as "something I built", never by name in strict communities;
  no link; a soft early-access offer is allowed.
- `personal-brand` — builder and practitioner credibility; no product, no link,
  no offer.
- `help-only` — being useful with zero commercial read; no product, no link, no
  offer.
- `lead-intent` — they openly asked for a tool or recommendation; one product
  mention allowed, the link stays in the bio, a low-pressure offer allowed.
- `network` — starting a relationship with one named person; mention the product
  only if they asked, no link, no offer.

Promo permissions are per-channel: in job-search and resume communities force
`help-only` even when another target looks tempting. A builder showing their own
project is a peer, not a prospect.
