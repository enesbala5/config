# Use exactly one brand register per post, chosen by topic

**Feeds stage:** social

Brand posts draw on several voice registers, but each post uses one baseline —
never an average of all of them. Pick the register the topic calls for and stay
in it:

- Proposition, product explanation, pricing, general → Precise Advocate
  (mechanisms over superlatives).
- Screening frustration, rejection, silence, support → Candid Career Strategist
  (honest and practical, never sentimental).
- Technical mechanisms, workflows, integrations → Application Operator
  (compressed, skeptical of busywork).

The register changes only because the topic changed, not to add variety. A post
that blends registers reads as mush; one baseline keeps it coherent. Each
register has its own vocabulary, so use its words rather than a blend.
