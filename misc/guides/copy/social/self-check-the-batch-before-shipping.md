# Self-check the batch before shipping

**Feeds stage:** social

Before delivery, verify:

- Run a mechanical check for dashes and links; empty output is a pass, any hit
  is a fail to fix and re-run.
- Every claim traces to a file just read or a commit in the material.
- Each personal option sounds like the person, not a brand; each brand option
  stays in one register, not a blend.
- Both accounts are represented, four options total, each with its `from:`
  line and a measured character count under the limit.
- Apply the stranger test: would a reader take the brand options for an ad, or
  the personal ones for a growth thread? Rewrite if so.

A mechanical check catches what the eye misses; the stranger test catches what
no regex can — copy that is technically clean but sounds like the wrong voice.
