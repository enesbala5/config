# Apply the hard format bans to every X option

**Feeds stage:** social

Mechanical, non-negotiable constraints on each option:

- No em dashes or en dashes — use commas or restructure. Check mechanically;
  the rule covers the surrounding batch message too, not just the drafts.
- No URLs in the post text. The link lives in the bio; a launch post may note
  that it goes in the first reply. If a draft depends on a link to make sense,
  rewrite the draft.
- No hashtags, no "Excited to share", no fake curiosity hooks, no growth-hacker
  cadence, no engagement bait.
- One post per option, 280 characters or fewer. When the story genuinely needs
  more, use a numbered thread of two to three posts, each 280 or fewer. Never a
  wall of text.
- At most one ask per option, and only when it is real (feedback on a screen, a
  question he wants answered).
- Measure the character count; do not estimate it.

The delivered draft is copy-paste ready: plain text, no quotes around it, no
markdown decoration, no code fence, no preamble or process narration.
