# Use a quiz to segment and gate only the result

**Feeds stage:** plan

A quiz earns engagement and produces segmentation data. Keep the quiz itself
ungated and gate the personalised result behind email capture.

Design 3–5 result categories, each with a name, a description and recommendations,
then tailor follow-up by result type. A shareable result format ("I got: Growth
Stage Marketer") extends reach beyond the people who take it. Counterexample:
gating the first question, which kills completion before the segmentation value is
earned.
