# Audit the leaky stage before chasing lurkers

**Feeds stage:** verify

Diagnose where members drop off before choosing tactics: joining but never posting
is an activation problem; posting once and disappearing is a retention problem;
never joining is a reach problem. Fix the identified stage instead of applying
generic "engagement" activity everywhere.

Counterexample: sending a weekly newsletter to 500 quiet members when the real leak
is that nobody replies to a first post.
