# Change one variable per test

**Feeds stage:** verify

Test a single meaningful change at a time. When two things move together and the
metric shifts, you cannot tell which one caused it, so the result cannot be
reused on another page.

A/B tests two versions with one change; A/B/n adds variants; multivariate tests
combine several elements and multiply the traffic needed. Isolation is the point
of the exercise, not a limitation of it.

Counterexample: redesigning the headline, hero image and CTA in one variant and
then crediting the headline when signups rise. The next page inherits a
"winning headline" that was never tested alone.
