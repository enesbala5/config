# Fix the bottleneck before optimising anything else

**Feeds stage:** verify

Every funnel has one constraint that limits throughput; improving anything else
is wasted effort. Zoom out before zooming in: rewriting email subject lines is a
local optimum if email is the wrong channel, and more conversion work will not
help a funnel that already converts well but has too little traffic. Diagnostic:
what single step, if fixed, would move the whole system? Fix that first.
