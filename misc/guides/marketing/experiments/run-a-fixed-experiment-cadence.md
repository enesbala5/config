# Run experiments on a fixed weekly-to-quarterly cadence

**Feeds stage:** verify

A programme needs rhythm, or tests launch ad hoc and are never concluded.

- **Weekly, 30 min:** check running tests for technical issues and guardrails.
  Do not call winners early; do stop a test whose guardrail is significantly
  negative.
- **Bi-weekly:** conclude finished tests, analyse, update the playbook, launch
  the next from the backlog.
- **Monthly, 1 hour:** review velocity, win rate and cumulative lift; replenish
  the backlog; re-prioritise with ICE.
- **Quarterly:** audit which patterns were applied, which winners were not
  scaled, and which funnel areas are under-tested.

Counterexample: a backlog that grows for months while the same test sits running
because no recurring slot owns the conclusion.
