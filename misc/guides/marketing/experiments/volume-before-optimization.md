# Diagnose reach before prescribing volume

**Feeds stage:** verify

Volume is a fix for one specific constraint, not a universal first step. When the
measured bottleneck is reach — too few attempts for any variant to be judged —
the fix is more output: set a quota (Hormozi's Rule of 100: 100 primary
advertising actions a day for 100 days) and scale it. When the bottleneck is
conversion, activation or retention, more volume only multiplies the same loss.
Run the bottleneck diagnosis first; reach volume is the branch it selects.
