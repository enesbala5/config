# A/B testing designs the test; copy writes the variants

**Feeds stage:** handoff

When a request is "write landing-page copy and test it against the current
version", it is two jobs. Experimentation owns the hypothesis, primary metric,
sample size, duration and decision rule. Copy owns the words in each arm.

Provide the test frame — the observation, the angle being tested, the metric, the
audience — then hand the drafting to the copy module. Keep the variants true to
the hypothesis rather than writing several unrelated pages.

Counterexample: using test-setup patterns to produce full page copy, yielding a
"variant" with no message strategy behind it and no way to attribute a result.
