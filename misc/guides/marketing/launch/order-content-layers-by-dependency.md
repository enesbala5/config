# Order the content layers so each informs the next

**Feeds stage:** plan

Produce campaign content in a fixed dependency order rather than by whichever
channel is due first:

1. Landing page copy — the canonical statement of the offer and message.
2. Email sequence — each email has one purpose, following the arc from problem to
   final call to action.
3. Social posts — platform-native, written after the core message is settled.
4. Short-form video scripts — written for screen and ear once the message works on
   the page.
5. Ad copy variants — three to four variants testing different angles or segments.
6. Content calendar — last, because it schedules assets that now exist.

Reversing the order is the common failure: ads and social get written from the
brief, the landing page then diverges, and the launch ships with claims that do not
match. Build the source of truth first.
