# Rewrite any copy that would work unchanged for a competitor

**Feeds stage:** verify

The substitutability test: unplug the product name and drop the piece into a
competitor's campaign. If it still works, it is not campaign copy — rewrite it
until it depends on this product, this audience and this angle.

This catches copy that passed every local check: grammatical, on-tone, free of
banned superlatives, and still interchangeable. Interchangeable copy is the symptom
of a campaign written from a category template rather than from positioning.
