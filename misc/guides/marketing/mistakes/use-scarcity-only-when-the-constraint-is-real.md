# Use scarcity only when the constraint is real

**Feeds stage:** verify

Scarcity and urgency raise perceived value, but they are legitimate only when a
genuine limit exists: a real cohort size, a real deadline, limited beta spots.
Manufactured urgency — fake countdown timers, invented stock limits — is the
manipulative version of the same lever. The ethical test: could you show the
customer the actual constraint without embarrassment? If not, do not use it.
