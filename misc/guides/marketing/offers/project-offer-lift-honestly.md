# Project offer lift honestly, one lever at a time

**Feeds stage:** plan

Change one value-equation lever per iteration — the lowest-scoring one — so the
result stays attributable. State expected lift as a range, not a promise: a
single-component change typically moves conversion 10–40%, and two consecutive
changes on different levers can stack to 2–3x. Anyone promising 5x from one
change is selling something.
