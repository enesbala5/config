# Default to an existing category; creation is the rare exception

**Feeds stage:** position

Category creation means selling the problem and the solution — the hardest, rarest
positioning style. Default to head-to-head or big-fish-small-pond in an existing
category that makes your strengths obvious; roughly 90% of recent tech IPOs
positioned in existing markets. Counterexample: chasing a new category because it
sounds visionary while buyers lack the frame to understand you.
