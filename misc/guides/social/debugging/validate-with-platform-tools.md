# Validate with platform tools

**Feeds stage:** verify

Use each platform's own validator rather than trusting one preview: Facebook Sharing Debugger (`https://developers.facebook.com/tools/debug/`), LinkedIn Post Inspector (`https://www.linkedin.com/post-inspector/`), X/Twitter Card Validator (`https://cards-dev.twitter.com/validator`), and metatags.io for a general check. All debuggers should show the correct preview before launch.
