# Make OG images 1200×630px

**Feeds stage:** build

Generate OG images at 1200×630px (about 1.9:1) and declare those values as the image `width` and `height`. That size works on all platforms; an image at the wrong size is the root cause of wrongly sized previews. Facebook's minimum is only 200×200px, but use 1200×630 for quality.
