# Shortlist candidates, then verify the exact trim

**Feeds stage:** listening

Shortlist from a folder with `earshot rank "a soft felt mallet hit on a wooden block" downloads/sfx/ --top 5`, then pull the best moments as sample trims with `earshot find winner.ogg "a single clean mallet hit" --top 3` (start / end in seconds). Each segment has a kind: `stroke` (one onset until decay) and `event` (strokes that belong together, e.g. a key's down + up) start 5 ms before the attack and end after the decay; `window` is a plain stretch for beds, to be crossfaded. `head`/`tail` report the first 5 ms / last 10 ms against the trim's peak (-30 dB or lower = clean); a trim marked 'head cut' or 'tail cut' starts or ends inside a sound — do not use it as is. `--kind event` returns onset-based trims only (hits, clicks, steps), `--kind texture` windows only; the default reads the query. Then `earshot describe winner.ogg --start 1.12 --end 1.48`: check the top tags fit and the shape (attack/decay) fits the picture. AudioSet labels are weak on one-shots under ~0.5 s: 'tagger unsure' or a near class (Zipper for a swish, Finger snapping for a click) is neutral; only an outright different class (Speech, Music, Engine, Vehicle) is a red flag. A real find result: `earshot find keys.ogg "a single mechanical key press" --top 4` → `0:03.94-0:04.19 (0.24 s stroke, z +4.1 strong); 0:10.60-0:10.86 ...`.
