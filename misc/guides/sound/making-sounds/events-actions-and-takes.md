# Events, actions, counts and takes

**Feeds stage:** making-sounds

A thing done several times in a row (footsteps, knocking, typing, coins, keys, clinking glasses) is played as the action when the words ask for it: "footsteps on gravel", "three knocks", "5 seconds of typing". "a footstep on gravel" or "a single knock on a door" is one event. `--events N` (MCP `events`) overrides: 1 = one event, 2+ = the action with N events. A counted action is one file ("four knocks on the table", "a countdown 3 2 1"); a count of separate things is that many files ("five coin pickups", "3 variations"). A length with an action ("three knocks, 2 seconds") is the file's length with events spread over it; "200 ms apart" sets the gap. Read the `played:` line to see what was played. A row example: `earshot make "a soft ui tick" -o count.wav --events 8 --dur 1.5` → `tick/key (1.50 s, peak at 0.81 s, -16 LUFS, clean)` and `played: 8 events as a row at 6.2 a second`. For a learned design, seeds 0, 1, 2 play its different recordings (fullest clean one first), then new takes. Ask for 6-12 takes of anything a game repeats (`--n 8`, "eight variations") and make them in a set (`"n": 8`) so they share one level.
