# Learned sounds are rendered from numbers, not played back

**Feeds stage:** making-sounds

A learned design is not a recording played back. earshot keeps each public-domain recording as numbers — the level of 56 bands every 2 ms, how tonal each band is, and the stereo image — and renders a fresh take from them with new noise and the request's controls. 309 designs are learned from 692 recordings; no audio file is stored in the repository, so every sound is generated by code when it is asked for. Seeds 0, 1, 2 walk through a design's recordings (the fullest clean one first), then produce new takes. Counterexample: where no recording of the thing exists, `make` either hands over the nearest design with a `makes no X` line or answers with a code recipe — neither is a learned take.
