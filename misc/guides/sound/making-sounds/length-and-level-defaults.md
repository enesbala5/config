# Length and level defaults

**Feeds stage:** making-sounds

An interface sound is 0.2 to 0.7 s; a motion tick 0.04 s, a thump 0.06 to 0.09 s, a logo hit about 0.3 s, a whoosh about 0.4 s, a riser 2.5 s; game figures run 0.7 s (coin) to 2.9 s (win fanfare); real things take their time (a door falling shut 2.5 s, distant thunder 7.7 s); a bed is 20 s unless a length is asked. Seconds in the words or `--dur` set the length of a whoosh, riser, figure, bed and action; a single struck sound rings as it rings and says so. A single file is as loud as its kind allows — true peak -1 dBFS, at most -14 LUFS, a bed -22 — so single files are NOT a mix. `--lufs L` (`"lufs"` in a spec entry) sets one file's loudness. Sounds made as ONE spec are levelled against each other as a first balance to mix from: in a scene's spec the bed came out 9 to 16 LU under the things done in it. Files are 48 kHz stereo (or `--mono`); the extension picks the format — wav/flac directly, ogg/webm/m4a/mp3 through ffmpeg — and for the web write `webm,mp3` because Ogg Vorbis does not play in Safari before 18.4. Music loops sit at -16 LUFS, ambience beds at -22. A learned bed is stitched from pieces of its recording and has no loop point at all: `earshot make "a campfire" -o fire.ogg --dur 24` → `fire/camp (24.00 s, peak at 19.96 s, -22 LUFS, seamless loop, clean)`. The same arguments give the same samples; `--seed` and `--n` give other takes.
