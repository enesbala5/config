# Shortest path to a made sound

**Feeds stage:** making-sounds

One call per sound: `earshot make "WORDS" -o FILE`. No model is loaded and nothing is downloaded; a one-shot takes a few seconds. Read the first line of the answer: `clean` or what the audit found, plus any `earshot makes no X` line. If the catalogue lacks the thing, switch to `earshot build "WORDS" -o FILE --part "..." --part "..."`, read `fit:` and `still off:`, and hand it over as `fit` says. Nothing else is needed for a normal request.
