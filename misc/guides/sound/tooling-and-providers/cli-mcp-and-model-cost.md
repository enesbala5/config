# CLI, MCP and the cost of loading models

**Feeds stage:** tooling-and-providers

CLI: `earshot <command> ... [--json] [--out result.json]`. Text output starts with a plain summary; times are m:ss.ss in text, seconds in JSON; errors are one line on stderr (`earshot <command>: error: ...`), exit 1. MCP keeps models loaded between calls: `claude mcp add earshot --scope user -e EARSHOT_THREADS=3 -- /path/to/earshot/.venv/bin/python -m earshot mcp`, or in `.mcp.json`: `{"mcpServers": {"earshot": {"command": "/path/to/earshot/.venv/bin/python", "args": ["-m", "earshot", "mcp"], "env": {"EARSHOT_THREADS": "3", "GEMINI_API_KEY": "${GEMINI_API_KEY:-}"}}}}` — the key line only for the optional llm tool; never write a literal key into a project file. Pass absolute paths; `full=true` returns all JSON. If Claude Code shows no earshot tools, start it with `MCP_TIMEOUT=60000` (PowerShell `$env:MCP_TIMEOUT=60000; claude`); `earshot mcp --warm` preloads models. Tools: make, make_set, sounds, build, measure, describe, match, rank, find, compare, ab, realness, timeline, sheet, critique, doctor, llm_critique, sfx_list/render, kit_render. Each CLI call is a new process that loads models first (~20-40 s even for a cached file); `--listen` (MCP `listen=true`) also ranks by sound and adds `heard as: ... (z)`, loading a model for 20-40 s — use it when a descriptive request came back as a guess or on a recipe with its words. For many calls use MCP or one Python script; the models load once and repeats take seconds. The 20 MCP tools are make, make_set, sounds, build, measure, describe, match, rank, find, compare, ab, realness, timeline, sheet, critique, doctor, llm_critique, sfx_list, sfx_render, kit_render. Models load on the first listening call and stay loaded; once they are loaded, `make` also ranks by how the designs sound and `build` does not load them again. Python entry points: `from earshot.make import make, make_set`, `from earshot.build import build`, `from earshot import sounds as catalogue` (`catalogue.render('step/heels', seed=1)` returns stereo float64 at 48 kHz with `meta['member']` naming the recording) or `from earshot import api` for everything in one namespace.
