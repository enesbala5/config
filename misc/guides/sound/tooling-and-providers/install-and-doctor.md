# Install from GitHub and check with doctor

**Feeds stage:** tooling-and-providers

This skill is the instructions; the tool is a Python package. If `earshot` is missing, install from GitHub — the name `earshot` on PyPI belongs to another project: `pip install "earshot @ git+https://github.com/Leonxlnx/earshot"` (making sounds: no model, no GPU) or `pip install "earshot[listen,mcp] @ git+https://github.com/Leonxlnx/earshot"` (adds listening and MCP). `earshot doctor` checks packages, ffmpeg, models (pinned revision, cache state); `--load` times them. Making needs only the first line; ffmpeg on PATH is needed for ogg, webm, mp3 and m4a. Listening downloads two open models (~1.1 GB to download, ~2.2 GB on disk) on first use. In a repo clone `pip install -e ".[all]"` does the same from the folder. On a shared machine set `EARSHOT_THREADS=2-3` (or `--threads 2` on any command). Python 3.10 or newer, CPU only; ffmpeg on PATH is needed only for ogg/mp3/m4a/webm and to read video. The base install (~350 MB) brings numpy, scipy, soundfile, soxr and numba and no model — nothing is downloaded when a sound is made; numba compiles the synthesis loops on the first sound and keeps them on disk, so later calls start at once. Extras: `mcp`, `listen` (torch, transformers, librosa; models ~1.1 GB download / 2.2 GB on disk), `measure`, `images`, `llm`, `all` — combine as `earshot[listen,mcp]`. `uv tool install "earshot[mcp] @ git+https://github.com/Leonxlnx/earshot"` also works (uv takes torch from the CPU index); update with `uv tool upgrade earshot`; torch from the default index is large on Linux, so install the CPU build first if needed. The plugin installs nothing itself: install the tool with the `mcp` extra, then `/plugin marketplace add Leonxlnx/earshot` and `/plugin install earshot@earshot`, which starts `earshot mcp` with `EARSHOT_THREADS=3` and adds `/earshot:make` and `/earshot:make-set`. Skills: `npx skills add Leonxlnx/earshot`, or copy `skills/earshot` and `skills/real-sound` into `.claude/skills/`. Repository layout for reference: `earshot/make.py`, `brief.py`, `recipe.py`, `build.py`, `pack.py`, `sounds/`, `synth/`, `data/resyn/` (numbers + CREDITS), `data/textures/`, `data/drums/`, `data/notes/`, `data/recipes/`, `forge/` (with `fit/`, `bank/`, `kits/`), `gallery.py`, `skills/`, `docs/`, `.claude-plugin/`, `eval/`, `tests/`.
