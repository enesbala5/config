# Editing rules

Rules that must hold when the `revise` intent edits, polishes, QAs, or refreshes
existing copy. Evidence bucket: `<config>/misc/guides/copy/editing/`.

- `preserve-core-message-and-voice.md` — edits keep the author's meaning and voice (evidence: editing).
- `hand-off-new-copy-to-write.md` — new-from-scratch work leaves revise (evidence: editing).
- `focused-dimension-passes.md` — edits run as separate single-dimension passes (evidence: editing).
- `back-check-prior-passes.md` — earlier passes are re-verified after each pass (evidence: editing).
- `draft-quality-sweep-before-handoff.md` — final quality sweep before a draft leaves (evidence: editing).
- `no-ai-tell-transitions.md` — delivered copy carries no machine-signal transitions (evidence: editing).
- `high-stakes-panel-gate.md` — persona panel gate on high-stakes copy (evidence: editing).
- `refresh-vs-rewrite-decision.md` — refresh vs rewrite chosen by message fit (evidence: editing).
- `refresh-covers-all-dimensions.md` — a refresh covers every refresh dimension (evidence: editing).
- `collaborative-edit-author-decides.md` — findings and fixes shown; author decides (evidence: editing).
