# Longform rules

What must be true when writing a technical how-to post. Evidence lives in
`<config>/misc/guides/copy/longform/`; rules never copy lesson prose. A rule
with several evidence pointers means several lessons converged on the same
requirement.

## Rules

- `collect-real-receipts.md` — drafting requires a recorded set of real inputs. (evidence: `longform`)
- `no-fabricated-setup.md` — missing receipts are waited out, never invented or misattributed. (evidence: `longform` ×2, compressed)
- `mine-referenced-repo-before-outlining.md` — a named git path is resolved and mined before outlining. (evidence: `longform` ×2, compressed)
- `derive-storyline-from-diffs.md` — beats come from chronological diffs; conflicts are raised. (evidence: `longform`)
- `walkthrough-shows-head.md` — walkthrough quotes HEAD, not history or log output. (evidence: `longform`)
- `body-follows-fixed-skeleton.md` — body starts at `# Introduction`; title is frontmatter-only. (evidence: `longform`)
- `introduction-opens-on-readers-setup.md` — Introduction opens in the reader's situation and ends in an end state. (evidence: `longform`)
- `walkthrough-step-shape.md` — each step runs goal → snippet → expected observation. (evidence: `longform`)
- `name-limitations-in-callouts.md` — limitations are named in callouts, not smoothed over. (evidence: `longform` ×2, compressed)
- `sharp-mechanisms-hedged-results.md` — mechanisms are definite; personal results are not universalized. (evidence: `longform`)
- `conclusion-is-a-mechanism-list.md` — Conclusion is mechanism bullets with an optional/required split, no pep talk. (evidence: `longform`)
- `use-technical-how-to-register.md` — register is first-person technical how-to, never marketing/SEO/brand. (evidence: `longform` ×3, compressed)
- `calibrate-on-authors-published-posts.md` — voice is calibrated on the author's newer published post, not older defects. (evidence: `longform`)
- `first-person-peer-voice.md` — voice is a competent peer with `you`/`I` and backticked mechanics. (evidence: `longform`)
- `no-question-openings.md` — posts never open on a question or fake-curiosity hook. (evidence: `longform` ×2, compressed)
- `no-blog-trope-filler.md` — filler tropes and prose emoji are cut. (evidence: `longform`)
- `callouts-have-a-job.md` — every callout has a short title and one real purpose. (evidence: `longform`)
- `fence-code-with-context-above.md` — code blocks are fenced with a language and introduced above. (evidence: `longform`)
- `match-frontmatter-contract.md` — frontmatter satisfies the declared portfolio contract in full. (evidence: `longform`)
- `no-image-assets.md` — no image asset is generated; image fields point to expected paths. (evidence: `longform`)
