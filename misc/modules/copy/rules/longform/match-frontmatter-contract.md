# Match the frontmatter contract

A post is written only into a destination whose frontmatter contract is declared
in `<config>/misc/modules/copy/references/`, and its frontmatter satisfies that
contract in full before the post is finished. The field-level contract itself is
a user decision held in `references/`, not hard-coded by this rule.

Evidence: <config>/misc/guides/copy/longform/match-the-portfolio-frontmatter-contract.md
