# Page-copy rules

What must be true when creating new page and marketing copy in the `write`
intent. Evidence: `<config>/misc/guides/copy/page-copy/`.

## Rules

- `five-inputs-before-page-copy.md` — all five human-supplied inputs precede drafting; evidence bucket: page-copy.
- `awareness-scoped-to-problem.md` — awareness is confirmed per problem, not per reader; evidence bucket: page-copy.
- `page-format-from-awareness-ladder.md` — format comes from the canonical ladder, not a default; evidence bucket: page-copy (two lessons).
- `advertorial-outer-arc-for-unaware.md` — unaware pages use an advertorial shell with SB7 later; evidence bucket: page-copy.
- `specific-claims-over-vague.md` — claims are specific or cut; evidence bucket: page-copy.
- `benefits-lead-features.md` — the reader gain precedes its feature; evidence bucket: page-copy.
- `mirror-customer-language.md` — vocabulary comes from voice-of-customer material; evidence bucket: page-copy.
- `lead-with-reader-outcome.md` — openings lead with the reader's problem or result; evidence bucket: page-copy.
- `cta-action-verb-plus-outcome.md` — CTA labels name action plus payoff; evidence bucket: page-copy.
- `cta-visible-and-clear.md` — CTA is early, repeated and unambiguous; evidence bucket: page-copy (two lessons).
- `risk-reversal-at-action-point.md` — hesitation is answered at the CTA; evidence bucket: page-copy.
- `headline-matched-to-message.md` — headline formula fits the single message; evidence bucket: page-copy.
- `narrative-over-feature-list.md` — page advances an argument, not a feature run; evidence bucket: page-copy.
- `how-it-works-numbered-outcome-steps.md` — steps are numbered, brief and outcome-bearing; evidence bucket: page-copy.
- `testimonials-specific-results.md` — testimonials prove results and are never invented; evidence bucket: page-copy.
- `one-idea-per-section.md` — each section carries one argument in logical order; evidence bucket: page-copy.
- `reader-addressed-voice.md` — copy is about the reader, not the company; evidence bucket: page-copy.
- `deliver-alternatives-and-annotations.md` — delivery includes rationale and options; evidence bucket: page-copy.
- `make-the-pain-felt.md` — the before state is concrete, not informational; evidence bucket: page-copy.
