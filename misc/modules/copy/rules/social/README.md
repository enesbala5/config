# Social rules

Domain rules for the `social` intent: X post batches and comment replies. Load
`<config>/misc/modules/copy/AGENTS.md`, then
`<config>/misc/modules/copy/rules/README.md`, then this index before any rule file.
Each rule states one thing that must be true; evidence lives in
`<config>/misc/guides/copy/social/`.
