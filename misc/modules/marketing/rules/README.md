# Rules

What must be true when using this module. Each rule points to lesson evidence in
`<config>/misc/guides/marketing/`. Rules never copy lesson prose; lessons never
change to fit rules.

## Sets

- [research/](research/README.md) — evidence gathering, sample floors, confidence labels, research briefs.
- [positioning/](positioning/README.md) — audience, problem ownership, category, angle, claims.
- [offers/](offers/README.md) — value equation, guarantees, packaging, scarcity, lead magnets.
- [channels/](channels/README.md) — channel choice, owned capture, community, lead capture.
- [launch/](launch/README.md) — pre-launch gate, sequencing, launch-day operations, adoption.
- [experiments/](experiments/README.md) — hypotheses, test validity, metrics, programme cadence.
- [handoffs/](handoffs/README.md) — strategy → copy and strategy → design boundaries.
- [mistakes/](mistakes/README.md) — anti-patterns, unsupported claims, ethical limits.

## Conventions

- One enforceable statement per rule.
- Always include `Evidence: <guide>/<bucket>/<lesson>.md` (bucket path is enough
  when several lessons support the same rule).
- If no lesson supports a rule, mark it as a user decision instead of inventing
  evidence.
