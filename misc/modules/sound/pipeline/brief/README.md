Owns the sound need for each cue, or an explicit "nothing".

## Route

Guide buckets: `placement-and-limits`, `film-sound`. Load
`<config>/misc/guides/sound/README.md`, the named bucket READMEs, then only the
lessons the task names.

## Adds / overrides

restraint decision.

## Done when

Every cue has either a sound need or an explicit "nothing".
