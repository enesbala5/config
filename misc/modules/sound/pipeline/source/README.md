# Stage: source

Owns per-category assets and their manifest.

## Route

Guide buckets: `tooling-and-providers`, `listening`. Load
`<config>/misc/guides/sound/README.md`, the named bucket READMEs, then only the
lessons the task names.

## Adds / overrides

Each file is measured and realness-checked on the exact trim that will be used;
a reading on a different trim does not carry over.

## Done when

Assets and manifest exist with numbers recorded per file on the used trim.
