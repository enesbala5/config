# Rules

What must be true when using this module. Each rule points to lesson evidence in
`<config>/misc/guides/sound/`. Rules never copy lesson prose; lessons never change to fit rules.

## Sets

- `acquire` — `<config>/misc/modules/sound/rules/acquire/README.md` — how a sound is obtained, read and handed over (`making-sounds`, `building-sounds`).
- `evidence` — `<config>/misc/modules/sound/rules/evidence/README.md` — what may be claimed, on what reading, and when to stay silent (`listening`, `placement-and-limits`).
- `soundtrack` — `<config>/misc/modules/sound/rules/soundtrack/README.md` — pipeline gates, licence policy and tool contracts (`film-sound`, `tooling-and-providers`).

## Conventions

- One enforceable statement per rule.
- Always include `Evidence: <guide>/<bucket>/<lesson>.md` (bucket path is enough
  when several lessons support the same rule).
- If no lesson supports a rule, mark it as a user decision instead of inventing
  evidence.
