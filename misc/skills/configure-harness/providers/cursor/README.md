# Cursor

## Start here

- Global rules: edit `misc/rules/general/` (deployed at `~/.cursor/rules`). For shared always-on rules, update the corresponding `misc/agents/AGENTS.md` entry too; see **Default instructions (AGENTS.md)** in `tools/pi/README.md`.
- Herdr Desktop agent status: see `tools/herdr/integrations/cursor/README.md` for the source hooks and Home Manager ownership. Don't edit the deployed `~/.cursor/hooks.json`.

## Apply and verify

Check that Cursor picks up the changed rule in a fresh chat. For the Herdr Desktop bridge, follow its guide's **Verify** section.
