# OpenCode

## Start here

Read `tools/opencode/README.md`. Edit the Nix modules in `nix/nixos/modules/home/programs/opencode/`, not the live `~/.config/opencode/cli.json` or `tui.json`. The guide maps CLI preferences, providers, MCP, and themes to their source modules.

## Apply and verify

Follow the repo guide for the NixOS switch, Home Manager service check, and smoke test in a new OpenCode process.
