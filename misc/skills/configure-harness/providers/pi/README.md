# Pi

## Start here

Read `tools/pi/README.md` for tracked settings, keybindings, themes, and extensions under `tools/pi/agent/`, and for the shared rules in `misc/agents/AGENTS.md`. Model configuration is generated from `nix/nixos/modules/home/programs/local-ai/`; don't edit `~/.pi/agent/models.json` or runtime state such as credentials and sessions.

## Apply and verify

Follow the repo guide for Home Manager-managed changes, Pi's `/reload` where documented, and the regression tests or smoke checks for the affected feature.
