## Lesson conventions

- One idea per file; small, concrete, actionable.
- Canonical buckets: `taste/`, `process/`, `typography/`, `color/`, `spacing/`, `layout/`, `hierarchy/`, `backgrounds/`, `motion/`, `copy/`, `mistakes/`, `qa/`, `notes/`. Create a new one only if nothing fits.
- Each lesson has a title, `**Feeds stage:** <bucket>` and a body. Lessons are standalone: **no `Source:` line and no article link**.
- Enrich an existing lesson instead of duplicating it; update the bucket README in the same pass.
