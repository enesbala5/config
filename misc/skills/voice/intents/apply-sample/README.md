# Apply a writing sample

Read the draft and the supplied sample or confirmed voice profile. Ask for whichever input is missing.

Match sentence length, diction, punctuation, openings, and transitions. With both a sample and a profile, use the sample for phrasing and rhythm and the profile for broader constraints. The sample overrides generic anti-tell preferences, including dash frequency.

Check that the rewrite retains the draft's facts and meaning without importing claims or personal details from the sample. Return the final prose unless the user asks for commentary. If asked to edit a file, preserve non-prose content and link targets, then briefly report the change.
