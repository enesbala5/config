# Build a voice profile

Start with the writer's own samples, not generic examples. Use 5–20 representative pieces when available; prefer recent writing unless the writer identifies an older piece as canonical. Look first at original posts and threads, then long-form writing, effective outbound emails or DMs, and finally relevant docs, changelogs, or site copy. Work from excerpts or files the user supplies; ask for samples if no usable sources are available. Separate public and private registers when they differ.

Record patterns you can point to in the writing. Note thin evidence rather than treating a one-off as a rule.

```text
VOICE PROFILE
Source basis: [sources and date/context]
Register: [public/private, formal/casual, etc.]
Voice: [core traits]
Rhythm: [sentence length, pacing, compression]
Diction: [word choice, capitalization, jargon]
Punctuation: [parentheticals, dashes, questions]
Claims and evidence: [specificity, certainty, receipts]
Structure: [openings, transitions, endings]
Avoid: [specific habits/tropes]
```

Reuse the latest confirmed profile when it's available. Save it only when requested, and don't add personal voice fingerprints to tracked files without explicit permission.

For Affaan / ECC voice with thin sources, use this provisional brief: direct, compressed, concrete. Prefer mechanisms, receipts, and numbers over adjectives. Use conventional capitalization, rare genuine questions, earned transitions, and a dry or blunt tone where appropriate. Avoid bait hooks, fake contrasts, “no fluff,” forced lowercase, LinkedIn cadence, “Excited to share,” generic founder-journey filler, and forced asides.
